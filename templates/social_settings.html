📖 How to Get Access Tokens
  1. Go to developers.facebook.com
  2. Create an App → Business type → Add Facebook Login and Pages API
  3. Go to Graph API Explorer → Select your Page → Generate Token
  4. Permissions needed: pages_read_engagement, pages_show_list
  5. For Instagram: also add instagram_basic, instagram_content_publish
  6. Convert to a long-lived token (valid 60 days) using Token Debugger
  7. Paste the tokens above and click Refresh Feeds Now
💡 Tokens expire every 60 days. When they expire, just generate a new one and paste it here. Full token auto-refresh comes with hosting.
