## Push Champions Connect to YOUR GitHub Repo
## Repo: https://github.com/hifyty/championsconnect

Run these commands ONE AT A TIME in your Terminal:

──────────────────────────────────────────────
STEP 1 — Go into your project folder
──────────────────────────────────────────────
cd ~/Downloads/church_app_full

(If you unzipped it somewhere else, adjust the path)

──────────────────────────────────────────────
STEP 2 — Set up Git and push
──────────────────────────────────────────────
git init
git add .
git commit -m "🎉 Launch Champions Connect"
git remote add origin https://github.com/hifyty/championsconnect.git
git branch -M main
git push -u origin main

──────────────────────────────────────────────
WHEN PROMPTED FOR PASSWORD:
──────────────────────────────────────────────
Username: hifyty
Password: [your GitHub Personal Access Token — NOT your GitHub password]

To get your token:
→ https://github.com/settings/tokens/new
  - Name: champions-connect
  - Expiration: No expiration
  - Check: ✅ repo
  - Click Generate token → Copy it immediately

──────────────────────────────────────────────
EVERY TIME YOU MAKE CHANGES AFTER THAT:
──────────────────────────────────────────────
git add .
git commit -m "describe what you changed"
git push
